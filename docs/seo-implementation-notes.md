# Anthem SEO Implementation Notes

## Architecture

- Replaced static HTML files and route handlers with typed Next.js App Router pages.
- Replaced `document.write`, DOM cloning, and navigation `innerHTML` with server-rendered React and small client components for navigation and form behavior.
- Centralized business configuration in `config/site.ts`.
- Centralized metadata creation in `lib/metadata.ts`.
- Centralized service and location content in typed data files.

## Metadata And Indexing

- Every indexable route has a unique title, description, canonical, Open Graph URL, and robots directive.
- Canonicals use `SITE_URL` with `https://anthemcv.com` as the production default.
- Vercel preview and development deployments are `noindex, nofollow` and disallowed by `robots.txt`.
- Production sitemap and robots output are generated by App Router metadata routes.

## Semantics And Linking

- Every page renders exactly one H1 before hydration.
- Primary pages include meaningful H2 and H3 sections.
- Services link to related services and California locations.
- Locations link to primary plumbing and HVAC services.
- Breadcrumbs, shared navigation, footer links, and calls to action use direct canonical URLs.

## Redirects

- Legacy `.html`, Colorado filename, Arizona alias, and duplicate standalone service URLs redirect directly to one canonical destination.
- No internal link points through a redirect.

## Validation

- `npm run lint` performs strict TypeScript validation.
- `npm run build` produces the server-rendered App Router build.
- `npm run seo:check` starts the production build and validates route status, metadata, canonicals, headings, internal links, stale slugs, and redirect behavior.
